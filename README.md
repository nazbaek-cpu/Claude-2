# Claude-2: HyperFrames video pipelines

| Folder | What it makes |
|---|---|
| [`fizik-reel/`](fizik-reel/README.md) | edits a talking-head selfie video: transcript, silence cuts, studio voice, retouch, product zoom, liquid-glass keyword animations |
| [`sticker-reel/`](sticker-reel/README.md) | builds a reel from a voiceover: face stickers, kinetic text, product cards, all timed by phrases of the script |
| [`cinematik-affiliate/`](cinematik-affiliate/README.md#cinematik-food-affiliate-preset-food) **Cinematik Food Affiliate** | the food-review look of cinematik-affiliate (`"preset": "food"`): yellow handwritten line over bold sans, studio voice, brisk pace |
| [`cinematik-affiliate/`](cinematik-affiliate/README.md#animasi-edukasi-buku-preset-edukasi) **Animasi Edukasi Buku** | the no-face motion-graphics reel for educational books (`"preset": "edukasi"`): scenes built on a sped-up voiceover with a clean voice chain, e.g. [`timbunan-chip`](cinematik-affiliate/projects/timbunan-chip/project.json) (Modul Konstruk Fizik T4 & T5) |
| [`cinematik-affiliate/`](cinematik-affiliate/README.md) | gives a talking-head take a clean cinematic affiliate look: warm muted grade, natural beauty pass, blur-in Inter typography behind the subject, yellow CTA, SFX |

Claude Code cloud sessions install all of them automatically (`.claude/hooks/session-start.sh`).
